# features/about

Page « À propos » de Quelques mots — homage à l'affiche Susan Kare (Apple, 1984).

## Composants
- `AboutHero` — wordmark « QUELQUES MOTS », pastilles de valeurs.
- `AboutShowcase` — fenêtre classique « ~/quelquesmots — Aperçu » (faux terminal).
- `AboutProgrammer` — prose en deux colonnes expliquant le motif.
- `Launchpad` — grille d'icônes de navigation rapide.
- `Signoff` — citation monument Stewart Brand + pied de page noir.
