# Feature Notifications

Gère les notifications regroupées, les onglets de filtrage et la pastille de l'en-tête.

## API publique (`index.ts`)
- `notificationsService`, `useNotifications`
- `NotificationRow`, `NotificationTabs`, `BellBadge` (≤ 50 lignes)

## Dépendances
- `features/auth`, `features/authors`, `lib/env.ts`, `lib/format.ts`
