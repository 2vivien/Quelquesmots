# Feature Reader

Gère l'expérience de lecture d'un texte (`/mots/[slug]`) : bandeau image, typographie serif, métriques et textes similaires.

## API publique (`index.ts`)
- `ReaderHero`, `ReaderHeader`, `ReaderBody`, `RelatedPosts`, `ViewTrackerMount` (≤ 50 lignes)

## Dépendances
- `features/authors`, `features/feed`, `features/interactions`, `features/posts`
