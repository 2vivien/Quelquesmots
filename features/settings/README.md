# Feature Settings

Gère les paramètres de profil, la signature de publication, la photo de profil, la déconnexion et la suppression de compte.

## API publique (`index.ts`)
- `profileSchema`, `useSettings` (saveProfile, changeAvatar, signOutAndRedirect, requestDeletion), `ProfileForm`, `PublishAsRadio`, `DangerZone`

## Dépendances
- `features/auth`, `features/authors`, `lib/env.ts`
